# 세계대전이야기 (World War Stories)

1차·2차 세계대전이 어렵게 느껴지는 공부를 위해, 한국어로 짧게 정리한 정적 사이트입니다. 영어 제목은 짧게 두고, 설명은 한국어로 씁니다.

나두 — 나의 모든 일상을 AI와 함께

나두 역사·신화로 이어지는 자매 사이트는 나두신화, 일리아스이야기, 그리스이야기, 로마이야기, 게르만이야기, 바이킹이야기, 이집트이야기, 페르시아이야기, 더 초즌 · 성경, 철학이야기, 대한민국이야기, 나두세계, 나두연표, 나두 허브입니다. 영화 체크리스트, 나두인물, 미국차 컬렉션, 브리티시 모터스, 이탈리안 모터스도 본문에서 잇습니다.

## 메뉴

- **홈** `/`
- **요약** `/summary` — 원인·경과·결과 세 줄과 조금 긴 요약. 1차가 2차로 이어진 설명.
- **진영** `/map` — 단계별 세계 지도. 전향국과 참전 날짜.
- **시기** `/phases` — 각 전쟁 다섯 시기.
- **연표** `/timeline` — 1914–1918, 1919–1939, 1939–1945. 그때 한반도는?
- **쟁점** `/issues`
- **전투** `/battles`
- **인물** `/people` — 초상 없음.
- **전후** `/aftermath`
- **이어짐** `/bridge`
- **퀴즈** `/quiz`
- **영화** `/films`
- **출처** `/sources`

## 개발

```bash
npm ci
npm run dev
npm run typecheck
npm run build
```

Next.js 15 (App Router) · React 19 · Tailwind CSS v4 · TypeScript. 페이지는 빌드 때 정적으로 생성됩니다.

콘텐츠는 `data/`에 있습니다. `NEXT_PUBLIC_SITE_URL`의 기본값은 `https://nadoo-worldwars.vercel.app`입니다.

## 적는 기준

조약과 참전일을 우리말로 다시 쓰고, 없는 인용문을 만들지 않습니다. 지도는 오늘날 국경을 도식으로 쓰며 1914년의 제국과 다르다고 적습니다. 확인이 약한 일화는 전해지는 이야기라고 적습니다. 영화 제목은 실제 공개 제목을 쓰고, 작품을 볼 수 있는 불법 사이트는 안내하지 않습니다.
